# Пакет для внедрения архива «Обещали.»

Версия: 21 октября 2026 года. Редакционный набор подготовлен для передачи разработчику. Продакшен не изменён.

## Содержимое

| Файл | Назначение |
| --- | --- |
| `obeschali-final-v2.json` | **Публикационный набор**: 67 историй, RU/EN, исходная схема и стабильные `id` и `n`. Использовать вместо прежнего массива историй. |
| `obeschali-context-v2.json` | RU/EN пояснения, сопоставляемые с историями по `id`. Пустые строки означают, что пояснение не требуется. |
| `obeschali-excluded-v2.json` | 14 исключённых оригинальных записей с редакционными причинами. **Не публиковать** как карточки. |
| `obeschali-original-81.json` | Неизменённая копия приложенного исходного датасета из 81 записи для сравнения и отката. |
| `obeschali-review-v2.md` | Решение по каждой из 35 ранее исключённых историй, включая 21 восстановленную, и повторная оценка прежних 46. |
| `obeschali-validation-v2.md` | Результат автоматической проверки данных. |
| `MANIFEST.sha256` | Контрольные суммы файлов пакета. |

## Как подключать

1. Найти в проекте текущий источник массива историй. Подключить `obeschali-final-v2.json` как замену контента, сохранив существующую схему карточки. Идентификаторы `id` и исходные номера `n` не перенумеровывать.
2. Если сайт показывает верхний «Контекст», брать `obeschali-context-v2.json[id].ru` или `.en` в зависимости от языка. Если строка пустая, блок не выводить. Дату, место и источник брать из метаданных основной записи, а не из контекста.
3. Истории из `obeschali-excluded-v2.json` не включать в маршруты, навигацию, подборки и внутренние ссылки. Если прежний сайт создавал отдельные страницы по ID, решить судьбу адресов исключённых историй с учётом существующего роутинга (например, редирект или страница архива); сами ID оставшихся записей не меняются.
4. Сверить отображение обеих языковых версий, индексы названий источников в `en.qsrc`/`en.osrc`, отсутствие ссылок на удалённые ID и число опубликованных карточек — 67. Сохранить старый набор как версию для отката.

В исходной схеме **нет** поля `context`. Поэтому основной JSON строго совместим с ней, а контекст передан отдельным файлом. Если проект уже хранит контекст иным способом, перенести эти формулировки в существующий механизм без дублирования даты и документа.

## Что изменено редакционно

- Повторно рассмотрены все 35 исключений: 21 история возвращена после проверки предмета цитаты, срока и результата; 14 остались вне публикации.
- Повторно рассмотрены прежние 46 историй на том же критерии; все 46 оставлены. Пограничные и косвенные сопоставления обозначены в тексте.
- Для `peskov-2024-youtube` описана фактическая недоступность сервиса без утверждения о доказанной формальной блокировке или июльском плане блокировать его.
- Для `siluanov-2016-pensii` объяснено, что «эти сценарии» — повышение пенсионного возраста в проекте бюджета 2017–2019 годов; последующую реформу не выдают за доказательство расчётов 2016 года.
- Для историй о месте экономики в топ-5, ВВП, энергоёмкости, инновационной продукции и высокопроизводительных рабочих местах подобраны результаты за нужный срок и сопоставимый показатель.
- Сохранены точные источники и оговорки к условным прогнозам, изменениям планов и риторическим заявлениям. Русский и английский результаты согласованы.
